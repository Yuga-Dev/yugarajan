About

From architecture to production support

I work across the whole stack and the whole lifecycle: technical design, implementation, .NET and Vue.js migrations, code review, deployment and the support that follows a release.

Most of my work sits in multi-tenant and distributed systems: domain-driven design, authentication and authorization, asynchronous and serverless processing on Azure, and database performance. Those foundations are what make AI features dependable once real users and real data arrive.

Agentic AI

AI-powered data platforms

I design and build the AI layer that maps and validates messy source data before it reaches the target system.

  • Built the semantic field-mapping engine with confidence scoring; low-confidence matches go to a human reviewer.
  • Implemented configurable validation across schema, business, relationship and cross-object rules.
  • Added enrichment and defaulting for missing data, and accepted flexible spreadsheet formats from many source systems.

Result Analysts review only the uncertain mappings instead of every field, and bad data is caught before it lands.
